# Terminal fonts

- `CascadiaMono.ttf`: Cascadia Mono, used for terminal Latin characters,
  symbols, and box drawing characters.
- `NotoSansJP-VF.ttf`: Noto Sans JP, licensed under SIL Open Font License
  1.1. See `LICENSE-NotoSansJP.txt`.
- `Koruri-Regular.ttf`, `Koruri-Bold.ttf`: Koruri 20210720, licensed under
  Apache License 2.0. See `LICENSE-Koruri.txt`.
- `Mejiro-Regular.ttf`, `Mejiro-Bold.ttf`: Mejiro 20220812, licensed under
  Apache License 2.0. See `LICENSE-Mejiro.txt`.
- `Roboto-VF.ttf`: Roboto variable font from Google Fonts, licensed under
  SIL Open Font License 1.1. See `LICENSE-Roboto.txt`.
- `Moralerspace-Regular.ttf`: Moralerspace Neon Regular 2.0.0, licensed under
  SIL Open Font License 1.1. See `LICENSE-Moralerspace.txt`.
- `SourceCodePro-VF.ttf`: Source Code Pro variable font, licensed under SIL
  Open Font License 1.1. See `LICENSE-SourceCodePro.txt`.
- `JetBrainsMono-VF.ttf`: JetBrains Mono variable font, licensed under SIL
  Open Font License 1.1. See `LICENSE-JetBrainsMono.txt`.
- `SymbolsNerdFontMono-Regular.ttf`: Nerd Fonts Symbols Only Mono 3.5.0,
  licensed under the MIT License. See `LICENSE-NerdFontsSymbols.txt`.
