# Terminal fonts

- `CascadiaMono.ttf`: Cascadia Mono, used for terminal Latin characters,
  symbols, and box drawing characters.
- `NotoSansJP-VF.ttf`: Noto Sans JP, bundled as the Japanese glyph fallback.
- `Koruri-Regular.ttf`, `Koruri-Bold.ttf`: Koruri 20210720, licensed under
  Apache License 2.0. See `LICENSE-Koruri.txt`.
- `Mejiro-Regular.ttf`, `Mejiro-Bold.ttf`: Mejiro 20220812, licensed under
  Apache License 2.0. See `LICENSE-Mejiro.txt`.

Both font files contain their SIL Open Font License terms in the fonts' name
metadata. Cascadia Mono is provided by the Microsoft Cascadia Code project;
Noto Sans JP is provided by the Google Noto Fonts project.

Koruri is provided by the Koruri project. Mejiro is provided by AndroPlus-org.
